# EduConnect — Redesign do Portal Acadêmico (UX/UI)

> Projeto de consultoria em Design de Experiência do Usuário (UX), Interface (UI) e Desenvolvimento Front-end desenvolvido para a reestruturação completa do portal acadêmico da **EduConnect**.

---

## Sobre o Projeto

Nossa equipe foi contratada pela **EduConnect** com o desafio de modernizar e otimizar a experiência digital de seus alunos e docentes. O portal acadêmico anterior apresentava problemas de navegação confusa, sobrecarga visual e falta de responsividade.

O objetivo deste projeto foi conceber uma interface **intuitiva, acessível, moderna e centrada no usuário**, transformando a maneira como a comunidade acadêmica interage com notas, frequências, materiais de aula e comunicados institucionais.

### Principais Objetivos Alcançados

- **Simplificação da Arquitetura de Informação:** Reorganização dos menus e fluxos principais para reduzir o número de cliques até as informações essenciais.
- **Identidade Visual Moderna:** Criação de um sistema de cores, tipografia e componentes consistentes.
- **Design Responsivo:** Adaptação fluida da interface para desktops, tablets e dispositivos móveis.
- **Prototipação e Implementação:** Entrega tanto da documentação estratégica/visual quanto do protótipo funcional navegável em código web.
